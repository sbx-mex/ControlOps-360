# Alcance del repositorio nuevo

Repositorio: `sbx-mex/ControlOps-360`.

## Sí se versiona

- Documentación funcional.
- Configuración de ejemplo sin rutas personales.
- Auditor de metadatos.
- Módulos VBA exportados como texto.
- Maqueta Excel sin datos de tienda.
- Pruebas y flujo de validación.

## No se versiona

- Excel operativos de tienda.
- Rutas locales reales.
- Archivos con datos de ventas, inventario o colaboradores.
- Credenciales, tokens o conexiones privadas.
- Histórico acumulado generado en operación.

Los proyectos existentes se usan únicamente como referencia de medidas y comportamiento; no son dependencias y no reciben cambios.
